# PSL Cricket Data Analysis

## Project Overview

This project focuses on **Data Analysis and Exploratory Data Analysis (EDA)** of PSL cricket ball-by-ball data from **2016–2024**.

The purpose of this project is to analyze match performance, scoring patterns, wickets, teams, players, and other important factors using real cricket data.

## Data Analysis Process

* Data Collection
* Data Cleaning
* Data Preprocessing
* Missing Value Analysis
* Exploratory Data Analysis
* Statistical Analysis
* Data Visualization
* Insight Generation

## Key Analysis

The analysis explores:

* Team performance and wins
* Runs scored
* Wicket distribution
* Scoring patterns
* Over-by-over scoring progression
* Batting performance
* Bowling performance
* Match and season trends
* Venue-based performance

## Visualizations

The project includes different visualizations such as:

* Bar Charts
* Histograms
* Line Charts
* Box Plots
* Heatmaps
* Distribution Plots

## Objective

The main objective is to transform raw PSL ball-by-ball data into meaningful insights that can help understand **cricket performance, scoring trends, and team patterns**.

PSL ball-by-ball dataset covering seasons from **2016 to 2024**.
